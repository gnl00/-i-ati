# v1.2.0

This release adds terminal access, conversation branches, and a dedicated task workspace, with improvements to model configuration, desktop automation, and chat responsiveness.

### What's New

- Added a single-task CLI and an interactive terminal UI for running the agent from the terminal.
- Added conversation branches, cross-chat task tools, and a dedicated task workspace for managing ongoing work.
- Added local knowledge base indexing and retrieval, local wiki tools, and chat history search.
- Added built-in Responses and Gemini request adapters, separate main, lite, and vision model roles, model capability sync, provider connection tests, and model-aware thinking controls.
- Added a native macOS computer-use bridge with visual action feedback and cursor trails, plus support for workspace image files and faster file search with bundled ripgrep.
- Added a smart welcome message stack and refined emotion inference, with state derived from user interactions.
- Expanded Telegram tools and workspace commands, improved streaming responses, and synchronized tool approvals across hosts.
- Refined provider, MCP, plugin, skill, memory, and knowledge base settings, with searchable model selection and clearer inline feedback.

### Fixes and Improvements

- Improved streaming chat responsiveness, transcript scrolling, history loading, reasoning disclosures, tool progress, and large tool-result rendering.
- Improved cancellation, command confirmations, workspace file boundaries, scheduled task execution, and recovery from interrupted skill installations.
- Improved web fetching and search extraction, added DuckDuckGo search, and preserved structured tool failures and stream termination errors.
- Improved artifact previews, desktop window cleanup, macOS fullscreen controls, and packaging of built-in provider definitions.

### Upgrade Compatibility

Version 1.2.0 removes automatic migrations for older stored model selections, MCP and plugin configuration, emotion state, scheduled-task schemas, and other retired data formats.

Direct upgrades from older installations are unsupported when those formats are present; legacy settings or emotion state may be lost, and databases using the old scheduled-task schema are unsupported.

Back up application data before upgrading and retain the previous application version for recovery.
