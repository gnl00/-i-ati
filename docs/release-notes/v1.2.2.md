# v1.2.2

### Fixes and Improvements

- Grouped chats by workspace, added chat search, and moved scheduled chats into Tasks.
- Improved streaming responsiveness and added an expanding, frosted message composer.
- Refined reasoning and tool disclosures, long-message controls, image previews, and message metadata.
- Added a clickable sidebar corner hint and native scroll bounce on macOS.
- Centered empty states in Memory and MCP settings.
- Fixed the welcome emotion briefly showing the default image before the saved emotion loaded.
- Added Telegram gateway start, stop, and status controls and improved Telegram network requests.
- Updated Electron to 44.5.0; macOS now requires version 13 or later.

Full changes: [v1.2.1...v1.2.2](https://github.com/gnl00/-i-ati/compare/v1.2.1...v1.2.2).
